## 三条铁律

1. **模型只负责理解和建议**：真正的执行权由确定的程序控制。
2. **动钱先确认**：敏感操作须暂停，等用户明确确认后沿原任务继续。
3. **银行结果说了算**：余额、限额和风控规则只在模拟银行，助理不自行判定交易成功。
