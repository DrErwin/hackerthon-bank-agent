# AI Banking Agent

为银发人群打造的银行智能助理：用自然语言理解金融意图，自主规划并代理执行转账、账单分析、跨场景联动等业务，配权限分级、敏感操作确认与注入防御。

> FinTechathon 2026 第八届深圳国际金融科技大赛 · 国内人工智能赛道（作品提交截止 2026-11-02）

## 三条铁律

1. **LLM 只动嘴不动手**——模型只理解、规划、回复；执行权在确定性代码手里。
2. **动钱必过确认门**——敏感操作暂停 → 前端确认 → 沿原任务继续。
3. **银行规则只在模拟银行**——结果只认银行返回，应用侧不复刻余额、限额、风控规则。
