# 跨场景联动模块 AI 开发规则

本目录归周恩宇。开工读[联动 PRD](../../../../docs/prd/06-跨场景联动-PRD-2026-09-23.md)和上级[业务模块规则](../AGENTS.md)；接口依赖以[公共契约](../../../../docs/contracts/公共契约-2026-09-23.md)为准。

- 联动只编排转账、账单等模块的公开能力；新增能力先向对应模块负责人提需求，不复制其内部流程、工具或数据。
- 依赖的公开入口尚未合入时，可在本目录按契约写用例和假实现；真实联调及可合并 PR 等前序能力进入 `main` 后完成。
- 每个联动 PR 写明依赖的模块能力和 PR 编号，并验证每一步失败、等待确认及恢复时的结果。
