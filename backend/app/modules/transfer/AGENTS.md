# 转账模块 AI 开发规则

本目录归梁爽。开工读[转账 PRD](../../../../docs/prd/01-智能转账-PRD-2026-09-23.md)和上级[业务模块规则](../AGENTS.md)；公开入口以[公共契约](../../../../docs/contracts/公共契约-2026-09-23.md)为准。

- 只实现本期转账能力，更新本模块的注册声明、工具和测试。v0.3 首条参考路径由 Erwin 按根目录 `AGENTS.md` 的临时安排实现，梁爽负责业务评测与审查；阶段收口后的扩展和维护回到梁爽。
- 转账提交前必须经过统一确认门和安全执行器；金额、账户或其他确认参数变化时，重新确认。成功与否以模拟银行结果为准。
- 需要新银行能力、公共字段或 API 时先提出问题，由公共目录负责人单独提交；涉及安全规则请 Ringo 审查。
