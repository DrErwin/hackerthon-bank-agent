# 账单模块 AI 开发规则

本目录归周恩宇（Ethan；2026-09-28 全员会由六水移交）。开工读[账单 PRD](../../../../docs/prd/02-账单分析-PRD-2026-09-23.md)和上级[业务模块规则](../AGENTS.md)；公开入口以[公共契约](../../../../docs/contracts/公共契约-2026-09-23.md)为准。

- 消费统计、异常识别和账单报告从本模块公开入口注册，按 PRD 的本期范围逐项提交。
- 报告卡片与敏感明细导出按契约分别声明权限和验证路径。
- 所需银行数据经公共接入层获取。缺字段或 API 时按上级规则提问题，先用符合契约的假数据验证模块流程。
