## 业务目的

让主 Harness 能在当前用户范围内理解预置称呼和保存必要上下文，同时不能把记忆当作权限、确认或银行事实。

## 交付

- 支持“妈妈”等演示称呼的预置记忆。
- 当前用户的上下文与摘要持久化适配。
- 用户隔离、受控写入、查看和删除的最小能力。
- 向 Harness 提供经过筛选的上下文，不传递认证秘密。

## 验收

- “给妈妈转 500 元”能取得当前用户的称呼线索，但仍由转账流程查询并核验真实收款人。
- 另一用户不能读取、引用或删除该记忆。
- 外部文本不能被直接保存为系统规则或长期指令。
- 删除后重新读取不再返回该条记忆。
- 记忆内容不能代替权限、当前确认、有效验证或银行结果。
- Ringo 对隔离和受控写入规则完成审查。

## Handoff

最小记忆和上下文接口可用后，将其交给 09 接入 Harness。
