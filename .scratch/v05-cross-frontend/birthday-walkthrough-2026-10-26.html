分叉总图（先看这个）

颜色对应下面各节：绿=正常流程，蓝=动钱三步，黄=价格/数量变化，紫=等确认/验证码时修改，红=停止/未知/断线，深绿=结果页。

说一句话开始（例：给妈妈过生日，预算 500 元，10 月 30 日前送到）
 └─ 补资料：预算金额 → 日期 → 配送资料（受控表单，不往聊天里贴原文）
     └─ 选商品（可多件，每件数量）
         └─ 采用方案（只是定计划，不动钱）
             ├─ 冻结 500 →【确认 + 验证码】→ 资金被冻结（花一笔前先锁住总额）
             │    ├─ 花 199 下单 →【确认 + 验证码】→ 从冻结里付款
             │    ├─ 蛋糕 268 下单 →【确认 + 验证码】→ 从冻结里付款
             │    └─ 全部办完 → 结果页：合计 467，未花掉的 33 释放回账户
             ├─ 分叉 A｜价格变了 → 说明“新价会变”，重新采用 + 重新确认（旧确认作废）
             ├─ 分叉 B｜数量/商品想改（等确认或等验证码时）
             │    ├─ 系统先证明旧动作没被后台领走、并安全封住旧尝试
             │    ├─ 然后回同一任务给新方案 → 重新核算 → 重新确认（必要再验证）
             │    ├─ 旧动作已被后台领走 → 不能改，只能按原单号核实
             │    ├─ 已建未付订单 → 订单不能改，可继续付款或停止
             │    └─ 明确失败且证实无订单 → 可“换一件 / 跳过 / 停止”
             └─ 停止（不再新办）
                 ├─ 只释放没花掉的部分（不退款、不撤单、不追加冻结）
                 ├─ 结果未知 → “待核实 + 原单号查询”，不显示完成/失败
                 ├─ 断线/刷新 → 恢复任务与已发生事实，不重复提交
                 └─ 系统失败 → 待核实，不伪造结果

① 起点与资料

一句自然语言开始：目标、预算、日期、配送。缺什么就补什么，配送原文只进受控表单。

  • D01：版式与字号是否认可
  • D04：个人预算是否只在服务端说“已采用”时显示
  • D05：配送是否只让填表单、之后只显示掩码

② 采用方案 → 动钱三步

“采用”只是定计划；冻结、下单、付款各问一次、各显示各自结果，没有一键全部确认。

  • D02：是否认可“采用只是定计划、三步各确认一次”
  • D06：最晚送达时刻本轮只收日期、页面相关处禁用

③ 分叉：价格变了 / 数量想改

价格变化必须重新采用并重新确认——旧确认不能批准新金额；数量改动会重算行小计与合计。

  • D02：改价后看到的新确认卡
  • D03：数量修改入口（已批语义、实现按后端能力）

④ 分叉：等确认 / 等验证码时申请修改

先证明旧动作没被后台领走并安全封住，才回到同一任务给新方案；领走了就只能核实原单号。

  • D03：入口与禁用态是否认可（完整实现按后端）
  • D07：未知/核实入口
  • D10：停止不等于退款

⑤ 分叉：停止 / 未知 / 收尾 / 断线

停止=不再新办，不等于退款或取消；未知不补 0、不写未付款；断线刷新保留已发生事实。

  • D10：停止与未知的说法是否认可
  • D07：释放未知时只给“待核实+原操作记录”

⑥ 终点：结果页

每笔订单、付款、冻结、释放都能逐项核对；冻结余款会释放，不等于个人预算剩余。

  • D04：完成页的金额口径
  • D10：不承诺现实送达/退款

最后：这一页要请您点头的 11 件事

  1. D01 版式与文案聊天里原地展开 + 当前卡展开、历史折叠；长明细进抽屉；单列/两列随屏宽。
  2. D02 动钱分三步采用只是定计划；冻结、下单、付款各问一次、各显示结果；没有“一键全部确认”。
  3. D03 数量与等待态修改语义已批、实现按后端能力；原型保留入口但部分按钮禁用，先走查设计。
  4. D04 个人预算口径只有服务端 adopted=true 才显示“已采用”；冻结余款不是个人预算剩余。
  5. D05 配送与隐私原文只进专用表单，之后只显示掩码，不让老人抄编号。
  6. D06 最晚送达18:00 时刻本轮只收日期、相关页禁用、不自动延期。
  7. D07 释放未知没有“只查原释放”入口前，只给“待核实 + 原操作记录 + 求助/明细”。
  8. D08 配送资料刷新配送已成功但未继续时刷新，本轮提示重填（不做受控引用恢复）。
  9. D09 结构化选品本轮沿用服务端候选按钮 + 原文，不做拆文案拼的卡片。
  10. D10 停止与未知说法停止=不再新办，不等于退款/取消；未知不补 0、不写未付款/未释放。
  11. D11 本轮验收边界只走查版式+文案+状态逻辑；视觉/键盘/200%/读屏/E2E 留后续。
