# 前端设计系统与组件基础

来源：2026-10-26 用户明确要求更新整个前端设计系统、引入常用组件与图标库，手机优先，并从完整交互体验考虑改造。此前完整审查和原型一并保留。

实施目录：`frontend/`。本阶段负责人 Erwin，执行者为本对话 AI。基线 `00543b4`。规格与实施票允许放在 `.scratch/`。

目标：确定 shadcn/ui + Radix / Vaul、Tailwind 4、Lucide、Sonner；统一视觉和组件语义，并让常驻服务入口、抽屉、等待、字号反馈实际使用这些基础能力。

验收：
- 设计系统覆盖信息组织、输入、确认、验证、反馈、异常恢复、适老化与响应式，且给出全业务替换顺序。
- 组件源码和锁定依赖纳入前端，保留既有 React、业务插槽与服务端契约。
- 长明细手机下方打开、电脑右侧打开，Esc/关闭回原处；办理结果持续显示。
- 常用服务在对话滚动后可找到；加载/等待使用真实状态且不伪造百分比。
- 提供可操作组件展示页和完整手机原型。组件测试、构建、浏览器验证各自留证。

本票不改业务状态机与后端。完整转账/账单/联动重排依据本次原型分后续前端票实施，避免基础库接入与交易流程变化混成一票。
