## 业务目的

用户会话到期重新登录后，通过原任务入口合法恢复未提交动作或查询已提交结果，界面按钮反映当前权限。

## 验收

- [ ] 复用既有会话、原任务恢复和结果查询协议；服务端重新核对身份、用户 / 轮次 / 任务归属及 Origin。
- [ ] 本人重新登录后原 task_id 可恢复：未提交动作返回新确认 / 按风险验证，已提交动作只返回原操作查询路径。
- [ ] 旧确认、旧验证、跨用户 / 轮次和重复冲突不能产生资金动作；请求回执、转换附近重启和重复点击可安全恢复。
- [ ] GET 快照、allowed_actions、待恢复列表、历史消息和 SSE 在转换后反映当前状态；旧事件重放不能恢复旧授权按钮。
- [ ] 不直接迁移其他目录任务 / 检查点，不保留冒用旧会话的分支；敏感秘密仍限专用入口且不落聊天 / 日志。
- [ ] HTTP 用例证明会话过期→重新登录→原任务恢复 / 查询且最多一次扣款；记录 React / 真实模型未验证部分，不提前关闭阶段验收。
