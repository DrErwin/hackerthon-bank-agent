## 业务目的

模型和底座能表达仅回复：普通闲聊或无明确业务意图时安全答复，不强造转账任务。

## 验收

- [ ] 提供模型无业务候选与受控仅回复公开结果，API 可区分回复与转账；保持原 TransferProposal 与转账调用兼容。
- [ ] 仅回复不登记业务任务、不调用转账 / 银行能力、不生成确认 / 验证或资金动作；不以成功转账任务包装普通回复。
- [ ] 意图判断由模型 / Harness 完成，API 无关键词分类；模糊业务意图可追问但不编造收款人、金额或授权。
- [ ] 聊天“确认”、诱导绕过验证或外部注入不能变成正式资金授权；输出及追踪仍遵守秘密隔离与脱敏规则。
- [ ] 模型结果缺失、矛盾或失败时安全停止并返回受控错误，不默认转账；明确转账继续原公共能力路径。
- [ ] 公开规划 / 理解入口与 DeepAgentPlanner 的模型接缝覆盖闲聊、模糊请求、确认文本、转账及异常；明确注明可重复模型与实际提供商证据的区别。

## 验证入口

模型适配接缝与 Harness 公共理解入口，断言无业务任务 / 银行调用；现有转账流程回归。
