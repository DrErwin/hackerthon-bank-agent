## 业务目的

底座用有效的新登录身份协调原任务恢复，调用存储与转账公开能力并记录全过程，不冒用过期会话。

## 验收

- [x] 仅接受当前有效身份和本人当前轮次原任务；非法身份在任务或检查点变动前拒绝。
- [x] 消费 01 / 02 的公开入口；不跨目录写数据库、复制 checkpoint 逻辑或放宽其他模块安全校验。
- [x] 未提交动作取得新会话确认 / 风险所需验证；提交不确定与处理中动作只回查原 operation_id，保留 task_id，不能重复执行原副作用。
- [x] 转换前必要审计写入失败则停止变动；中断后能恢复原转换，并记录旧 / 新会话、原 / 新运行及原操作关联，历史证据保留。
- [x] 当前会话旧的确认和验证不能被重新绑定为新授权；允许安全取消或读取终态，不修改实际银行结果。
- [x] 通过 Harness / TransferRuntime 公开入口验证真实存储、安全门、转账和模拟银行，模型使用可重复候选时明确标注；同会话恢复回归通过。

## 验证入口

Harness / TransferRuntime 公共入口，接真实存储、安全和模拟银行；不把模拟模型当作真实模型验收。
