## 业务目的

让同一用户在同一演示轮次内把原任务安全关联到有效的新登录会话，保留原任务及操作身份。

## 验收

- [x] 提供存储自有公开转换入口，核对用户、轮次、当前任务归属、目标会话有效性和任务版本；跨用户、跨轮次、过期目标会话及并发冲突拒绝。
- [x] 保留 task_id、原 operation_id、业务参数和历史记录；会话转换不生成银行动作或新任务。
- [x] 转换结果不将旧确认 / 验证引用当作新会话授权，不篡改历史确认、验证或审计事实；当前授权引用的处理有明确公开语义。
- [x] 转换原子且可恢复，同一合法转换重复调用不重复生成记录；冲突不留下半转换状态。
- [x] 通过公开存储入口测试上述正常、拒绝、重复与并发情形，并提供调用说明。

## 验证入口

存储公开入口；无需启动模型或银行。
