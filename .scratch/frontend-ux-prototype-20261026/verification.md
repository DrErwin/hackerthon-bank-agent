# 原型验证记录

2026-10-26。原型使用虚构数据，仅在页面内存中运行。

## 实际浏览器验证

- 转账：选择女儿 → 填 300 元 → 更换付款卡后金额保留 → 核对 → 示例验证码 → 成功回执。
- 新收款人：填写示例姓名/卡号、核对掩码、使用该收款人继续填写金额。保存常用在原型内存中演示，正式接口尚需补齐。
- 账单：分类筛选、医院明细抽屉、关闭回原位置；切换上月后日期、总额和单笔金额一致（9月总额2940元、医院352元）。
- 自动扣费：停扣核对、示例验证、原项目显示结果。
- 减支：选择两项，第一项完成后进入第二项，最后汇总两项49元。
- 生日：选择日期、填写示例联系人/电话/地址，在核对页回显；返回表单保留未提交草稿。演示终点为预算核对。
- 独立状态入口覆盖等待、结果未知、失败、断线恢复、空数据、风险提示与补充验证。
- 390px iframe 布局与桌面布局均有真实浏览器截图；这属于浏览器视口验证。
