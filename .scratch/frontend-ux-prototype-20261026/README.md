# 银行助手交互优化原型

2026-10-26，方案讨论稿。对应本次「完整检查前端交互并提供一版优化原型」的请求。

打开 `index.html` 即可体验；所有资料均为虚构示例，操作仅改变页面内存中的原型状态。刷新重新开始。

设计目标：办理所需的信息同屏可见；用选择替代记忆与输入；每次只请用户做一个清楚的决定；用简短、亲切、准确的提示推动下一步。

范围：首页、转账/新增收款人/核对/验证/回执、账户与收款人、账单/明细、自动扣费/退订、三个生活安排、办理记录，以及等待、结果待核实、失败、恢复和空状态。

这是一版独立原型。初评源码基线为 `9a479ea`，已补核最新主线 `00543b4` 的生日页面。用户后续授权的设计系统与组件基础在独立工作区实施。完整评审与功能差异见 `review.md`。
