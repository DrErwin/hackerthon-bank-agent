## 一、项目一句话

为**银发人群与数字能力较弱的用户**打造一个 AI 银行智能助理：用自然语言对话理解金融意图，自主规划并执行业务操作
（转账、账单、理财、卡片、订阅、跨场景联动），并配备完整的权限分级、敏感操作确认与注入防御机制。

## 八、同步边界与仓库

本地仓库是本项目唯一事实源；飞书文档面向团队阅读，同步方向为本地 → 飞书，飞书上的改动不回流。

- **Git 仓库**：已初始化（`main` 分支，本地）。提交格式与远端建立步骤见 [docs/agents/git-workflow.md](agents/git-workflow.md)。
- **飞书同步**：知识库《FinTechathon 2026 项目文档》四分区。`tools/feishu_publish_all.py` 使用 `CURATED_SOURCES` 白名单，只发布当前执行入口、总体路线与状态、已冻结的长期复用文档。
  - 三条命令都可重复跑：`plan`（只看会推哪些）· `publish`（推内容）· `mount`（挂进知识库分区，已在库里的跳过）
  - 清理旧资料：`archive-plan` 只看将移出知识库的文档；`archive` 将其保留到 Drive 归档文件夹，不直接删除。
  - 状态文件 `.feishu_state.publish.json`（标题 → doc_id）。**标题是飞书认文档的唯一键**，改标题会新建一篇而不是更新，所以已发布文档的标题写在 `TITLE_OVERRIDES` 里固定住。
  - 执行顺序：`plan` → `publish` → `mount`；飞书上的改动不回流，何时同步由人决定。
- **仓库专有**：未进入白名单的技术细节、历史记录、调研、会议材料、工具和 Agent 协作约定只留在仓库，需要时由链接或负责人提供。
