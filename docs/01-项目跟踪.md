## 二、协作流程

### 沟通节奏

- **例会**：一周至少一次，倾向周二 / 周四，提前协调（不固定日期）
- **日常**：随时在群里说，卡点第一时间发出来
- **三种求助途径**：问 AI → 群里问 → 私聊 Erwin
- **例会形式**：每人讲这几天的推进、卡点、下一步，不用做 PPT

### 需求与文档流程

各模块 PRD 初稿 → Erwin 整合总 PRD → 团队评审 → 契约冻结 → 开发

### 代码协作（开发阶段启用）

- **开分支前先读 `docs/principles/` 三份**：业务并行 / 安全底座 / Review 与合并
- 仓库为唯一代码事实源；`main` 分支保持可运行
- 个人在 feature 分支开发，通过 PR 合并，Erwin 审核
- 提交信息写清「做了什么 + 为什么」
- **禁止提交真实密钥或敏感信息**
