**队员开工流程（2026-09-30）**：说明身份 → 定位本人正式交付包 → 明确接受 → AI 自动记录领取 → 检查并安装缺失的通用 Skill → `to-spec → to-tickets → 按票执行`。开发票使用 `implement` 并做 `code-review`；评测、设计和文档票按交付物验收。流程细则、记录字段及 Skill 来源见[队员开工规范](agents/delivery-workflow.md)。只咨询下一步不代表已经领取。

```text
交付包 / 工作线：<链接与本人范围>

详细规格与票据：<链接或待建立>

```

记录经提交、推送和合入后供队员拉取；飞书同步按现有规则由人决定时间。改共享跟踪时只更新本人条目，保留其他工作线记录。
