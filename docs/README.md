- **v0.3.0 · 普通转账纵向链路**：已收口（2026-10-11，含明示例外）。
- **v0.4.0 · 账单、完整安全、完整前端与订阅代扣**：**已收口**——2026-10-22 完成联合验收（含例外 E1—E10，[联合验收记录](versions/v0.4.0/acceptance-evidence-2026-10-22.md)），**PM 2026-10-24 正式接受**；口径为「按现有证据接受、单会话不部署、不等于 Ringo 真人安全签核」，**不写"全部通过"**。

详细完成事实见各版本 `completion.md`；当前任务、开放问题与交付包登记见[项目跟踪](01-项目跟踪.md)；团队阅读版见飞书《01 项目跟踪》（源文件 [团队工作台](team/当前工作台.md)）。

## 阅读与维护

- 看某阶段承诺：打开该版本的 `requirements.md`。
- 看某阶段事实：打开该版本的 `completion.md`。
- 看负责人、排期和实时状态：查看 `01-项目跟踪.md` 与飞书进度表。
- 看当前工程规格和任务：查看 `.scratch/`。
- 进入下一里程碑前，先更新当前版本的 `completion.md`，写明验证证据、差异和遗留。
- 新增未来需求时先放入对应计划版本，不为未来版本提前创建实施票。
