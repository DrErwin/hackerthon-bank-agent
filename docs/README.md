## 阅读与维护

- 看某阶段承诺：打开该版本的 `requirements.md`。
- 看某阶段事实：打开该版本的 `completion.md`。
- 看负责人、排期和当前状态：查看 `01-项目跟踪.md`；飞书以实际同步时间为准。
- 看当前工程规格和任务：查看 `.scratch/`。
- 进入下一里程碑前，先更新当前版本的 `completion.md`，写明验证证据、差异和遗留。
- 新增未来需求时先放入对应计划版本，不为未来版本提前创建实施票。
