## 验收标准

1. 保持转账、账单、订阅既有能力；完成联动三个生活目标的正常与关键异常 E2E（真实模型 + 页面 + HTTP + 隔离模拟银行/生活服务），按[联动验收设计](../../../evals/cross/representative-cases.md)核对实际结果、依赖阻断、部分成功、恢复和收尾。依赖缺失明确阻塞，不默认豁免生日场景。
2. 安全评测能够证明确认、权限、注入防御和隐私边界。
3. 演示环境可重置，结果可重复。
4. 已知限制和遗留问题有明确记录。

## 本版本不做

- 为提高展示数量而新增未验证场景。
- 真实银行和生产部署。
- 比赛材料最终提交动作。
