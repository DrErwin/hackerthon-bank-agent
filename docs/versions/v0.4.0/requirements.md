# v0.4.0 需求：账单、联动与完整安全扩展

> 阶段目标：在已验证的纵向框架上完成账单分析、跨场景联动和完整安全能力。

## 背景

普通转账先验证公共框架；后续业务应复用同一 Harness、契约、安全入口、银行接缝和审计能力，而不是另建运行体系。

## 范围

- 完成账单分析公开能力和评测。
- 完成跨场景联动公开能力和评测。
- 补齐安全底座与安全评测集。
- 验证跨模块只调用公开能力，确认与验证记录按可信引用交接。
- 将三个业务场景接入统一前端和运行日志。

## 验收标准

1. 账单和联动场景复用 v0.3.0 公共框架。
2. 业务模块不直接访问其他模块私有工具或银行表。
3. 涉及资金的跨场景动作逐笔经过确认和安全检查。
4. 三个场景的业务与安全评测达到各自 PRD 标准。

## 本版本不做

- 订阅、卡片、理财等候选扩展场景。
- 多 Agent 通用调度平台。
- 比赛提交材料的最终制作。
