# v0.2.0 需求：公共契约与架构基线

> 阶段目标：冻结跨模块接口、安全与银行字段、总体架构和目录边界，使各负责人可以并行开发。

## 背景

PRD 已明确业务目标，但业务、底座、安全、银行和前端仍需要共同的状态、字段和调用边界。

## 范围

- 冻结总体架构、Agent Harness、恢复和审计边界。
- 冻结公共契约、银行接口、确认验证及安全审计字段。
- 建立后端、前端和评测集目录骨架及归属说明。
- 建立业务并行、安全开发、Review 与合并原则。
- 建立评测目录和最小验收口径。

## 验收标准

1. 公共字段与状态有唯一文档来源。
2. 各目录负责人和禁止越界事项明确。
3. 转账、账单、联动、安全、银行和前端的接缝可以被实现。
4. 契约变更有分级处理流程。

## 本版本不做

- 公共契约代码和业务功能实现。
- 真实 Harness、模拟银行和前端的运行验证。
- 完整评测数据集。
