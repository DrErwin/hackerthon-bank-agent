## 状态更新规则

- 任务开始、阻塞、完成时，当天更新飞书甘特图的状态、日期和阻塞原因。
- 范围与验收变化先改本地事实文档；仅调整日期或执行顺序时更新本计划与飞书甘特图。
- 依赖真实接口的工作先用契约 stub 继续；等待不会变成整条工作线停工。
- 同一人最多保留两个未合 PR，每张票、分支和 PR 只对应一个目录。
- v0.4 的账单和跨场景允许准备评测，不在 v0.3 验收前开始业务实现。
