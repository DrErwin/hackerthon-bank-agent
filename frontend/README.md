# frontend —— 用户前端（React）

归属：梁爽负责，六水协助（2026-09-25 Erwin 确认）。

放什么：对话界面、进度与等待展示、敏感操作确认（确认单 / 验证码 / 人脸三个安全交互）、结果与报告卡片、适老化交互（大字 / 高对比 / 语音播报 P1）。接口面 = [契约大纲](../docs/contracts/公共契约-2026-09-23.md)第 6 章接口与五链路（聊天 / 确认 / 验证 / 报告 / 事件与恢复）。

2026-10-01阶段安排：梁爽、六水本阶段只交普通转账关键流程原型图；Erwin临时做简易前端用于真实接口联调，10-10前可联调、10-12前阶段验收。后续完整前端仍采用React + Vite + TypeScript，类型复用公共契约（架构§8），不为简易前端另定业务或安全规则。

边界：**前端只展示和收集用户动作，不做权限判定**（安全底线，见 [principles/02](../docs/principles/02-security-platform.md)）；登录口径 = 演示固定用户 + 自动登录（契约 6.3）。

前端节点：原型目标10-05、最晚10-07（**实际10-06入库**）；Erwin简易前端10-06～10-10、联调10-10～10-12（**已交付**）。v0.3 收口后按[完整前端工作线交付包 01](../.scratch/frontend-complete/packages/01-v04-complete-frontend.md)推进：通用底盘 + 业务线插槽，v0.4 实现转账、账单两场景并替换简易前端（原型五类画面走查确认后开工，stub 先行）；联动（v0.5）与新业务线在 [`frontend-complete/`](../.scratch/frontend-complete/spec.md) 追加前端接入小包（新业务线 PPRD 定稿即加）。完整前端不阻塞v0.3，替换尚未开始。
