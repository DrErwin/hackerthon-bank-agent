# frontend —— 用户前端（React）

归属：梁爽负责，六水协助（2026-09-25 Erwin 确认）。

放什么：对话界面、进度与等待展示、敏感操作确认（确认单 / 验证码 / 人脸三个安全交互）、结果与报告卡片、适老化交互（大字 / 高对比 / 语音播报 P1）。接口面 = [契约大纲](../docs/contracts/公共契约-2026-09-23.md)第 6 章接口与五链路（聊天 / 确认 / 验证 / 报告 / 事件与恢复）。

脚手架（React + Vite + TypeScript，2026-09-29 由 Vue3 改定，理由：接入拷贝式组件库生态）在 UI/UX 规范与原型走查后创建，计划 10-06 开始；类型从 `backend/app/contracts/` 导出生成，不手写一份（架构 §8）。组件路线（shadcn 系拷贝式组件等）由设计周评估定案。

边界：**前端只展示和收集用户动作，不做权限判定**（安全底线，见 [principles/02](../docs/principles/02-security-platform.md)）；登录口径 = 演示固定用户 + 自动登录（契约 6.3）。

前端节点：09-29～10-05 完成适老化规范、三场景主要原型与迭代；10-06～10-10 完成骨架和普通转账完整链路；10-20 前三场景前端完整可用；10-21～11-02 体验打磨与最终提交。契约已冻结，设计产物按计划完成后进入实现。
