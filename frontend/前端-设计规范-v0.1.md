# 前端设计规范 v0.1

> 2026-10-26：当前设计与组件规则见 [设计系统 v0.2](DESIGN.md)；完整任务改造见 [交互改造方案 v0.2](交互改造方案-v0.2.md)。本文件保留历史。

> 主题色 **#FF6A00** ｜ 核心三个词：**简单 · 明晰 · 清楚**
> 手机优先 · 适老化 · 全局一套（转账第一个落地，规范不按场景做）
> 本规范只管「长什么样」；「怎么用」（语音、引导卡片、反馈）留给「用户体验规范」。

## 设计原则

- **简单**：一次只说一件事，能点（选项卡片）就不让打字。
- **明晰**：字大、对比高、说人话，一眼看懂。
- **清楚**：每个动作有回执；状态用「图标 + 文字 + 颜色」，色盲也能懂。

## 1. 主题色与功能色

**主题色（橙）**

| 用途 | 色值 |
|---|---|
| 主题色（按钮 / 强调 / 选中描边） | `#FF6A00` |
| 按下态 | `#E05E00` |
| 浅底（选中 / 高亮背景） | `#FFF1E6` |

**功能色（不动）**

| 用途 | 色值 |
|---|---|
| 成功 | `#067647` |
| 失败 / 危险 | `#B42318` |
| 警示 | `#B54708`（必须带 ⚠️ 图标） |

**文字（近黑，不用浅灰）**

| 用途 | 色值 |
|---|---|
| 主文字 | `#111827` |
| 次要文字 | `#374151` |
| 弱文字 | `#6B7280`（仅时间戳） |

**背景 / 边框**

| 用途 | 色值 |
|---|---|
| 页面底 | `#F5F6F8` |
| 卡片 / 输入框底 | `#FFFFFF` |
| 边框 / 分割线 | `#D0D5DD` |

> **橙底按钮配深字**（`#111827`）：橙底白字对比不够，适老化要高对比，所以主题按钮用深字、不用白字。
> **金额**：用主文字色 `#111827` 加粗放大，**不用红色**（红色只留给失败 / 危险）。

## 2. 字号

| 层级 | 字号 | 加粗 |
|---|---|---|
| 金额 / 关键数字 | 28px | 是 |
| 页面标题 | 22px | 是 |
| 正文 / 消息 | 18px | 否 |
| 按钮文字 | 18px | 是 |
| 次要说明 | 16px（地板，不再小） | 否 |
| 时间戳 | 14px | 否 |

字体用系统默认（苹方 / 思源黑体），不引入花哨字体。所有字号跟随系统「字体放大」，不写死。

---

## 3. 触控与间距

- 主按钮高 **56px**；次级按钮 / 选项 **48px**；输入框 **56px**；可点区域 ≥ **48 × 48px**。
- 卡片间距 16px，卡片内边距 20px。
- 主按钮、输入栏都在**底部**，拇指够得着。

---

## 4. 组件（简版）

| 组件 | 规范 |
|---|---|
| 消息气泡 | 用户：右，浅橙底 `#FFF1E6` 深字；助手：左，白底描边深字；气泡内金额加粗 |
| 输入栏 | 话筒 → 输入框 → 发送；话筒 48px 圆钮，按住变橙；发送键橙底深字，无内容置灰 |
| 引导卡片 | 白底描边、圆角 16px、高 48px；选中变浅橙底 + 橙描边；**不默认替用户选** |
| 确认单卡片 | 标题「请确认」+ 关键要素逐行大字（金额 28px 加粗）+「确认办理」（橙）「取消」（白底描边） |
| 验证码 | 6 位大格输入，上方标「模拟验证码」；**绝不出现在聊天气泡** |
| 结果 / 报告卡 | 状态标签（浅底 + 图标 + 深字）+ 金额 / 分类 / 摘要 |
| 按钮 | 主（橙底深字）/ 次（白底描边）/ 危险（深红白字）/ 禁用（灰） |
| 状态标签 | 处理中 / 等您补充 / 等您确认 / 结果待核实（警示色 + 「查询结果」按钮）/ 成功 / 失败 |

## 5. 布局（手机竖屏）

```
┌─────────────────────────┐
│ 顶部栏（标题 + 会话状态）    │  56px，白底深字
├─────────────────────────┤
│      聊天流（消息 / 卡片）   │  中间可滚动
├─────────────────────────┤
│ 底部输入栏（话筒+输入框+发送） │  64px，固定底部
└─────────────────────────┘
```

输入栏固定底部，键盘弹起跟着上移。确认单 / 引导卡片在聊天流内**高亮**，不弹窗把用户带离对话。

---

## 6. 适老化要点（一页纸）

1. **大**：正文 18px 起、金额 28px、按钮 48px 起。
2. **清**：文字近黑、高对比、说人话（「这笔钱没转出去」≠「交易失败」）。
3. **稳**：每个动作有回执（「已经办好了」/「还差一步」）。
4. **少**：引导卡片降认知负担，一次一件事。
5. **语音**：话筒长按 + 说完自动停，转写可点改，失败可打字兜底。
