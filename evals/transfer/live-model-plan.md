## 1. 当前可以直接执行的数量

选出 **35 个功能样本**。其中 `TF-CNF-03[嗯]` 与 `SEC-C-001/v03` 共用同一实际运行，按安全集要求独立运行三轮；其余各一次，所以共 **37 次样本执行**。同一轮保存一份原始证据，功能和安全分别判定，不重复调用模型。安全判定仍需核对证据，不因关联编号自动变为通过。

一次样本执行可能包含开场、后续聊天、多个模型内部请求。37 是用例执行数，不是供应商 API 请求数或 token 数。共享“嗯”三轮每次都使用新隔离状态，不能拿一次模型回答复制成三轮。

| 收款人表达 | TF-PAY-01、02、03、06、07、09、10、11 | 8 | 姓名、关系、手机号意图、备注匹配、同名及多卡歧义、关系不唯一、未知对象 |

同一功能的确定性变体继续独立测，例如 TF-PAY-08 的第二个候选、TF-PAY-04/05 的完整卡号及 TF-PAY-12—15 的输入错误，均保留在离线全集。手机号和卡号通过专用表单进入受控后端，不为了测这些分支把完整号码送给模型。

TF-INP-15 测入模前拒绝秘密，TF-INP-17 注入供应商故障，均不需要真实供应商调用。其余未入本重点清单的功能样本也没有被记成真实模型通过。重点集不能单独满足原 21 个标准任务成功率及全部 AF 联合验收；报告仍保留原分母和未执行项。

## 2. 直接运行现有 CLI

在仓库根目录、已有依赖的 Python 环境执行下列 PowerShell。只选择现有样本，不改运行器，不读取或打印 API Key；每次 CLI 调用生成新的结果目录。`--jobs` 只影响并发速度，不减少调用量。

```powershell
$liveCases = @(
    'TF-PAY-01', 'TF-PAY-02', 'TF-PAY-03', 'TF-PAY-06',
    'TF-PAY-07', 'TF-PAY-09', 'TF-PAY-10', 'TF-PAY-11',
    'TF-INP-01', 'TF-INP-02', 'TF-INP-03', 'TF-INP-04',
    'TF-INP-06', 'TF-INP-07', 'TF-INP-08', 'TF-INP-09',
    'TF-INP-10', 'TF-INP-11', 'TF-INP-12', 'TF-INP-13',
    'TF-INP-14', 'TF-INP-16', 'TF-INP-18',
    'TF-CNF-01', 'TF-CNF-03[嗯]', 'TF-CNF-03[好]', 'TF-CNF-03[行]',
    'TF-CNF-05', 'TF-BNK-01', 'TF-BNK-02',
    'TF-VFY-14', 'TF-VFY-19', 'TF-QRY-03', 'TF-QRY-12', 'TF-OBS-11'
)
$caseArguments = foreach ($sampleId in $liveCases) { '--case'; $sampleId }
python evals/transfer/run_live_eval.py --live-glm --config .env.local-demo.json --jobs 4 @caseArguments
$firstRunExit = $LASTEXITCODE

# 第一批已含“嗯”第一轮；后面两次才是第二、第三轮。
$extraRunExits = @()
foreach ($repeatIndex in 2..3) {
    python evals/transfer/run_live_eval.py --live-glm --config .env.local-demo.json --case 'TF-CNF-03[嗯]'
    $extraRunExits += $LASTEXITCODE
}
if ($firstRunExit -ne 0 -or @($extraRunExits | Where-Object { $_ -ne 0 }).Count -gt 0) {
    throw '真实模型重点评测存在失败或阻塞；请查看三个独立运行目录，保留全部结果。'
}
```

不要只给 `--case TF-CNF-03`，它会展开“嗯/好/行”三个样本；额外轮次只需要 `TF-CNF-03[嗯]`。也不要重复传同一个 `--case` 来表示三轮，现有 CLI 会把选择 ID 去重。

35 个首轮样本和两次追加采样均需保留；追加单样本通过不能覆盖首轮其他样本的失败。汇总时“嗯”须列出三个实际运行目录、时间和结果，安全侧逐轮引用对应记录。

程序分支继续运行完整离线功能评测，避免依赖手工减掉分支：

```powershell
python evals/transfer/run_live_eval.py --react-dist frontend/dist
```

此命令没有 `--live-glm`，不调用真实模型。需要现有 React 构建和 Playwright 浏览器；缺这些时页面用例记录 Blocked。完整依赖准备、故障和证据限制见 [运行说明](README.md)。
