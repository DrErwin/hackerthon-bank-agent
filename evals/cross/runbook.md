## 隔离与启动入口

本次工作区是 Codex 管理的独立 worktree。启动时以本工作区为根目录，禁止执行默认使用 8000/5173 的 `tools/start_local_dev.ps1`。预选端口为后端 **8165**、前端 **5265**；启动前重查占用，占用时停下选新端口并同步 origins/proxy，不能停止别人的服务。

本机准备配置为根目录被忽略的 `.env.cross-e2e.json`；数据在 `.mnemon/v05-cross-e2e/prep-20261025/`，其中 `application.sqlite3` 含任务/检查点/审计，`mock_bank.sqlite3` 含银行/生活服务事实。独立秘密已固定保存，重启不能再生成。普通用户 U1、管理员 demo-admin，轮次以本地配置实际值记录；相同 U1/D1 仅在独立数据库中使用，不能与共享服务交叉请求。

以下命令供前置就绪后的执行回合使用，本轮未启动这些服务。后端依赖可复用现有虚拟环境，**必须显式设置本 worktree 的 PYTHONPATH**，避免 editable 安装导入主工作区代码：

```powershell
# 从本 worktree 根目录运行；BANK_LOCAL_CONFIG 中不得指向共享数据目录。
$taskRoot = (Get-Location).Path
$env:PYTHONPATH = Join-Path $taskRoot 'backend'
$env:BANK_LOCAL_CONFIG = Join-Path $taskRoot '.env.cross-e2e.json'
& 'D:\hackerthon-bank-agent\backend\.venv\Scripts\python.exe' -m uvicorn app.agent_platform.local_demo:create_local_app --factory --host 127.0.0.1 --port 8165 --workers 1 --no-access-log
```

另一终端进入本 worktree 的 `frontend/`（只安装本工作区忽略的依赖）：

```powershell
npm ci
$env:VITE_API_PROXY_TARGET = 'http://127.0.0.1:8165'
npm run dev -- --host 127.0.0.1 --port 5265 --strictPort
```

用户页 `http://127.0.0.1:5265/`，管理页 `http://localhost:5265/admin`；两者 origins 已列入独立配置，前端须处于 real-api 模式。只停止本轮保存的进程，不按端口杀进程。重启案例沿原目录/秘密恢复；新案例新建配置和数据目录，从既有后端种子入口播种，不删旧数据或重置共享银行。准备库仅作入口构建检查，不直接充当正式案例基线。

## 运行与证据

使用 [覆盖清单](coverage-plan.md) 展开每个不同判断分支；实际运行前为每个变体写清输入、种子/基线、触发步骤、预期状态/金额/次数，再开始页面操作。自动化脚本尚未实现；当前执行入口是上述真实服务加浏览器人工操作，不是全自动运行器。

1. 浏览器从自然表达开始，记录实际输入和必要选择；不直接调用内部 start 方法替代页面。
2. 记录方案采用和**每项**敏感确认/验证前后的页面、有效交互、父子任务。方案采用不能当作动作确认。
3. 关联脱敏模型调用、HTTP/SSE、审计、原操作和银行/订单前后事实；没有模型层采集能力则该层 blocked，不凭助手文字填通过。
4. 分开计数：工具请求尝试数、银行写请求数（含相同 operation_id 重试）、银行已提交操作数、已结算业务效果数。未知恢复应先查原操作，已成功效果最多一次；不能仅凭最终余额相同认定没有重复提交。
5. 对照卡片/聊天/回执和事实。重跑必须保留失败批次、原任务和原操作，修复后新批次引用旧批次。

实际运行后使用模块统一归档：`evidence/YYYY-MM-DD/<唯一批次>.json.gz` 与同名 `.md` 摘要，截图放同日 `<批次>/XL-S01/<变体>/` 等附件目录。采用同日 `manifest.json` 索引，写解压后 JSON 的 sha256、案例/变体、状态分布、断言统计和附件路径；不覆盖报告。未运行时不生成成功报告，结构参见 [批次模板](batch-template.md)。

不得归档 Cookie、授权头、验证码、密钥、完整账号或配送原文。保留脱敏请求关联、服务端受控引用和证据缺口；原始敏感材料留本机受控区，不提交数据库或原始 HAR。脱敏后仍须可核对任务与操作关联。

200% 缩放、纯键盘、读屏、真机软键盘分别写设备/工具、操作、结果/截图或录屏；浏览器仿真不能代替真机。AI 审查、离线测试、真实模型、HTTP、页面 E2E、PM 体验接受、Ringo 本人签核各有独立状态，不能相互代签。
