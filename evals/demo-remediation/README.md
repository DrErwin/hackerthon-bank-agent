先按仓库本地 demo 文档启动隔离数据目录的后端与前端。使用已有本地配置，不复制密钥到命令或报告。脚本不启动应用、不更改原演示库。

```powershell
python evals/demo-remediation/safety_classification.py --config <本地配置路径> --output <新的结果路径>
python evals/demo-remediation/http_probe.py --base-url http://127.0.0.1:8007 --data-directory <隔离数据目录> --output <新的结果路径>
python evals/demo-remediation/collect_bank_evidence.py --data-directory <隔离数据目录> --task <实际任务ID> --output <新的快照路径>
```

HTTP 运行器只允许127.0.0.1，默认Origin对应前端5177。用 `--case privacy_help --case privacy_value` 定向复验。运行器拒绝覆盖已有证据。分类脚本的head记录代表运行时应用基线，脚本本身在实施票11分支后续提交；提示及语料hash已记录。

键盘已实测金额修改、按钮确认、验证提交和账单候选选择；不声称完整无障碍验收。窄屏、200%放大、真实语音未验收。失败重试、重复审批/验证、过期卡片、跨会话与所有权拒绝主要由各实施PR的定向回归覆盖，不能写成全部经过真实模型页面故障注入。
